1. INTRODUCTION                                                    *jishiben*

jishiben.nvim is a lightweight notebook plugin for Neovim. Notes are stored
as markdown in a single file and edited directly inside a floating window.

==============================================================================
2. COMMANDS                                                *jishiben-commands*

:JishibenAdd [text]                                            *:JishibenAdd*
    Append `- [ ] [text]` to the markdown file. If [text] is omitted, an input
    prompt is shown.

:JishibenOpen                                                 *:JishibenOpen*
    Open the real markdown storage file in a floating window.

:JishibenToggle                                             *:JishibenToggle*
    Toggle the checkbox on the current line in the markdown buffer.

:JishibenDelete                                             *:JishibenDelete*
    Delete the current line in the markdown buffer.

:JishibenPick                                                 *:JishibenPick*
    Open markdown checkbox lines in the snacks.nvim picker.
    Requires snacks.nvim.

:JishibenClear                                               *:JishibenClear*
    Clear all content from the markdown file.

==============================================================================
3. CONFIGURATION                                      *jishiben-configuration*

Call the setup function to configure the plugin: >lua

    require("jishiben").setup({
      storage_path = vim.fn.stdpath("data") .. "/jishiben.md",
      win = {
        title = " Jishiben ",
        title_pos = "center",
        border = "rounded",
        width = 60,
        height = 20,
      },
    })
<

Options:

  storage_path  `string`                                *jishiben-storage_path*
      Path to the markdown file that stores all notes.
      Default: `vim.fn.stdpath("data") .. "/jishiben.md"`

  win.title  `string`                                      *jishiben-win.title*
      Title displayed on the floating window border.
      Default: `" Jishiben "`

  win.title_pos  `string`                              *jishiben-win.title_pos*
      Position of the title: "left", "center", or "right".
      Default: `"center"`

  win.border  `string|string[]`                           *jishiben-win.border*
      Border style for the floating window.
      Default: `"rounded"`

  win.width  `number|nil`                                    *jishiben-win.width*
      Width of the floating window. When nil, auto-calculated (max 80).
      Default: `nil`

  win.height  `number|nil`                                  *jishiben-win.height*
      Height of the floating window. When nil, auto-calculated (min 20).
      Default: `nil`

==============================================================================
4. EDITING                                                    *jishiben-editing*

When the floating window opens, you are editing the actual markdown file.
Normal markdown editing works as usual.

  q       Close the floating window. Modified content is written first.

Checkbox lines follow standard markdown task-list format, for example:

  - [ ] inbox item
  - [x] finished item

==============================================================================
5. SNACKS PICKER KEYMAPS                              *jishiben-picker-keymaps*

The following keymaps are available inside the snacks.nvim picker:

  <CR>    Toggle the selected checkbox line.
  <C-x>   Delete the selected checkbox line.
