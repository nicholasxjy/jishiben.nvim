1. INTRODUCTION                                                    *jishiben*

jishiben.nvim is a lightweight notebook plugin for Neovim. Notes are stored
as markdown in a single file and edited from a two-pane TUI floating layout.

==============================================================================
2. COMMANDS                                                *jishiben-commands*

:JishibenOpen                                                 *:JishibenOpen*
    Open the sidebar and editable content pane.

:JishibenNote                                                 *:JishibenNote*
    Capture a timestamped note under the `## Notes` section.

:JishibenTodo                                                 *:JishibenTodo*
    Add an unchecked task under the `## Todos` section.

:JishibenClear                                               *:JishibenClear*
    Clear all content from the markdown file.

==============================================================================
3. CONFIGURATION                                      *jishiben-configuration*

Call the setup function to configure the plugin: >lua

    require("jishiben").setup({
      storage_path = vim.fn.stdpath("data") .. "/jishiben.md",
      win = {
        title = " jishiben.nvim ",
        title_pos = "center",
        border = "single",
        width = 96,
        height = 24,
        row = 2,
        col = 10,
      },
    })
<

Options:

  storage_path  `string`                                *jishiben-storage_path*
      Path to the markdown file that stores all notes.
      Default: `vim.fn.stdpath("data") .. "/jishiben.md"`

  win.title  `string`                                      *jishiben-win.title*
      Title displayed on the sidebar floating window border.
      Default: `" jishiben.nvim "`

  win.title_pos  `string`                              *jishiben-win.title_pos*
      Position of the title: "left", "center", or "right".
      Default: `"center"`

  win.border  `string|string[]`                           *jishiben-win.border*
      Border style for the floating windows.
      Default: `"single"`

  win.width  `number|nil`                                    *jishiben-win.width*
      Total width of the floating layout. When nil, auto-calculated (max 96).
      Default: `nil`

  win.height  `number|nil`                                  *jishiben-win.height*
      Height of the floating layout. When nil, auto-calculated (max 24).
      Default: `nil`

  win.row  `number|nil`                                        *jishiben-win.row*
      Row offset of the floating layout. When nil, centered vertically.
      Default: `nil`

  win.col  `number|nil`                                        *jishiben-win.col*
      Column offset of the floating layout. When nil, centered horizontally.
      Default: `nil`

==============================================================================
4. EDITING                                                    *jishiben-editing*

When the floating layout opens, the left pane lists sections and the right
pane edits the selected section content. Normal markdown editing works in the
right pane.

Right pane mappings:

  n         Add a timestamped note under `Notes` and enter Insert mode.
  t         Add an unchecked task under `Todos` and enter Insert mode.
  <Space>x  Toggle the current task between `[ ]` and `[x]`.
  q         Close the floating layout. Modified content is written first.

Sidebar mappings:

  <Enter>   Open the selected sidebar section.
  n         Open `Notes`.
  t         Open `Todos`.
  q         Close the floating layout. Modified content is written first.

Use normal markdown task-list editing directly in the file, for example:

  ## Notes
  - 09:30  inbox idea

  ## Todos
  - [ ] inbox item
  - [x] finished item

Use |:JishibenClear| to wipe the file content while keeping the markdown file.
