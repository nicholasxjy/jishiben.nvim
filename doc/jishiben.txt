1. INTRODUCTION                                                    *jishiben*

jishiben.nvim is a lightweight notebook plugin for Neovim. Notes and todos
are stored in separate markdown files and edited from a two-pane TUI floating
layout.

==============================================================================
2. COMMANDS                                                *jishiben-commands*

:JishibenOpen                                                 *:JishibenOpen*
    Open the sidebar and markdown content pane.

:JishibenNote                                                 *:JishibenNote*
    Append raw text to the notes file.

:JishibenTodo                                                 *:JishibenTodo*
    Append raw text to the todos file.

:JishibenClear                                               *:JishibenClear*
    Clear both markdown files.

==============================================================================
3. CONFIGURATION                                      *jishiben-configuration*

Call the setup function to configure the plugin: >lua

    require("jishiben").setup({
      notes_path = vim.fn.stdpath("data") .. "/jishiben/notes.md",
      todos_path = vim.fn.stdpath("data") .. "/jishiben/todos.md",
      win = {
        title = " jishiben.nvim ",
        title_pos = "center",
        border = "single",
        width = 96,
        height = 24,
        row = 2,
        col = 10,
      },
    })
<

Options:

  notes_path  `string`                                    *jishiben-notes_path*
      Path to the notes markdown file.
      Default: `vim.fn.stdpath("data") .. "/jishiben/notes.md"`

  todos_path  `string`                                    *jishiben-todos_path*
      Path to the todos markdown file.
      Default: `vim.fn.stdpath("data") .. "/jishiben/todos.md"`

  win.title  `string`                                      *jishiben-win.title*
      Title displayed on the sidebar floating window border.
      Default: `" jishiben.nvim "`

  win.title_pos  `string`                              *jishiben-win.title_pos*
      Position of the title: "left", "center", or "right".
      Default: `"center"`

  win.border  `string|string[]`                           *jishiben-win.border*
      Border style for the floating windows.
      Default: `"single"`

  win.width  `number|nil`                                    *jishiben-win.width*
      Total width of the floating layout. When nil, auto-calculated (max 96).
      Default: `nil`

  win.height  `number|nil`                                  *jishiben-win.height*
      Height of the floating layout. When nil, auto-calculated (max 24).
      Default: `nil`

  win.row  `number|nil`                                        *jishiben-win.row*
      Row offset of the floating layout. When nil, centered vertically.
      Default: `nil`

  win.col  `number|nil`                                        *jishiben-win.col*
      Column offset of the floating layout. When nil, centered horizontally.
      Default: `nil`

==============================================================================
4. EDITING                                                    *jishiben-editing*

When the floating layout opens, the left pane lists files and the right pane
opens the selected markdown file. Normal markdown editing works in the right
pane. The plugin does not require any specific markdown structure.

Right pane mappings:

  n         Open `Notes`.
  t         Open `Todos`.
  q         Close the floating layout. Modified content is written first.

Sidebar mappings:

  <Enter>   Open the selected sidebar section.
  n         Open `Notes`.
  t         Open `Todos`.
  q         Close the floating layout. Modified content is written first.

Use normal markdown editing directly in each file, for example:

  # Ideas
  - Draft plugin README

  - [ ] inbox item
  - [x] finished item

Use |:JishibenClear| to wipe both files while keeping the markdown files.
